# AI Supermarket Demand Forecasting & Inventory Assistant

An end-to-end AI-powered supermarket analytics platform that combines Python, Machine Learning, PostgreSQL, FastAPI, LLM, RAG, and Data Engineering to provide intelligent demand forecasting and inventory management.

## 🚀 Features

### Demand Forecasting
- Product-level demand prediction using XGBoost, Random Forest, and Prophet
- Seasonal pattern detection and trend analysis
- Multi-horizon forecasting (7, 14, 30 days)
- Confidence intervals for predictions

### Inventory Analytics
- Stockout risk detection and alerting
- Identification of slow and fast-moving products
- Reorder optimization and suggestions
- Safety stock recommendations

### AI Assistant
- Natural language question answering
- RAG-powered document retrieval
- Business insight generation
- Trend explanation and root cause analysis

### Data Pipeline
- Synthetic data generation for realistic supermarket data
- Automated ETL pipeline with data validation
- PostgreSQL database with optimized schemas
- MLflow for model tracking and versioning

### API & Integration
- RESTful API with FastAPI
- Comprehensive API documentation
- Docker containerization
- Production-ready configuration
